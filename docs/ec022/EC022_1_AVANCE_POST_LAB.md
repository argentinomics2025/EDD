# EC-022.1 — Avance posterior a la validación del laboratorio

ARGUS confirmó el commit d28d20dd, 28 pruebas unitarias y migraciones/RLS, lectura REST, ingestor exclusivo, idempotencia, concurrencia, rollback y revocación de permisos temporales en el laboratorio `ec022lab08f2e7bbd3db`. Es evidencia recibida del usuario; no se volvió a ejecutar esa batería.

Las tres migraciones del laboratorio fueron copiadas sin cambios a `migraciones_lab/` y sus hashes Git coinciden con los candidatos documentados. No se ha verificado una aplicación limpia completa ni una recuperación desde respaldo: no son todavía migraciones aprobadas para producción.

Las notas originales del BCRA en `preser_uva.xls` identifican los nuevos préstamos UVA desde mayo de 2016. Se corrigió el parser para omitir los marcadores anteriores en lugar de interpretarlos como desembolsos cero: 126 meses, mayo 2016–octubre 2026, hash de fuente `9d1c4d02952295958be4eec92f61b559a58a99242399de0824d196bf16720155`. El archivo informa monto desembolsado en miles de pesos y tasa nominal anual ponderada por monto. El monto UVA de octubre 2026 y el de la serie 4291 no son conciliables como subconjunto y total sin aclarar metodología y universo; no se derivó ni publicó ninguna relación entre ambos. Ver fuente BCRA y sus notas: https://www.bcra.gob.ar/archivos/Pdfs/PublicacionesEstadisticas/preser_uva.xls y https://www.bcra.gob.ar/archivos/Pdfs/PublicacionesEstadisticas/es_series.txt.

Se añadieron preparadores que vuelven a parsear los bytes de diez archivos locales y producen manifiestos de ingesta por fuente, con SHA-256, valores derivados del parser y fechas de publicación desconocidas como nulas. Requieren que el operador suministre la **hora real de recuperación de la fuente**; una hora de procesamiento o una fecha inventada no sirven. Una prueba de procesamiento sin escrituras, usando una marca temporal sintética solo para el ensayo, obtuvo respectivamente: UVA 252 valores, tasas BCRA 802, saldos BCRA 1426, CVS actual 7608, CVS histórico 5051, salarios actual 120, salarios histórico 169, IPC 237, RIPTE CSV 387 y RIPTE PDF 772; sin duplicados de serie/período dentro de cada fuente. Los dos archivos de RIPTE siguen siendo ediciones distintas y su discrepancia de noviembre 2017 requiere aprobación explícita. No se ha cargado ninguno al laboratorio.

El escritor de archivos permanece desactivado por defecto y utiliza el rol exclusivo y la función idempotente existentes, sin aprobar ediciones. Se ha preparado el acoplamiento parser→manifiesto→escritor para archivos, pero aún faltan pruebas de integración y carga real, catálogo de metadatos y verificación económica. Los históricos UVA/CER de la API recuperados anteriormente contienen observaciones y hashes de páginas, pero no todos los bytes originales de cada respuesta: falta resolver su procedencia verificable sin atribuir a un archivo local el hash de una respuesta distinta. No se pueden dar por incorporados.

El workflow manual de lectura ahora exige la variable `EC022_PROBE_ENABLED=1`, incorpora los nuevos tests y emite una anotación de error si falla. No tiene cron ni escritura de base y no se ejecutó; una anotación de Actions no equivale a una alerta externa operativa. La organización Supabase informa plan Free, pero no se obtuvo presupuesto disponible ni cupo de Actions; DEC-006 no está verificado. La guía de respaldo y reversión es una propuesta sin ensayo de recuperación.
